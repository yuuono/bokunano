# 日本語言い換えテスト方針

## 1. 目的

訓練で見せていない日本語表現を使って、同じ意味ASTから正しいPythonコードを生成できるかを評価する。

単純操作の意味、Pythonコード、テストケースは変えず、日本語表現だけを未学習にする。訓練用表現とテスト専用表現の分離は、文字列規則や無作為抽出ではなく、作成者が意味と自然さを確認した人手選定結果で固定する。

## 2. 承認済み545件の分割

人間が承認した545件を次の二つへ分ける。

| 辞書区分 | 件数 | 用途 |
|---|---:|---|
| `train` | 522 | 訓練、検証、通常テスト、組合せ・反復・境界値テストの指示生成 |
| `test_only` | 23 | 言い換えテストの指示生成だけ |

`test_only`は、操作ごとの先頭要素や乱数で自動選定しない。人手で選んだ23個の`expression_id`を[`build_approved_expression_dictionary.json`](../../config/build_approved_expression_dictionary.json)へ固定し、残り522件を`train`とする。

`test_only`の表現本文だけでなく、その`expression_id`も訓練指示、訓練用プロンプト、few-shot例、既存表現の参考例へ渡さない。接続形も同じ辞書区分として扱い、終止形だけを訓練側へ流用しない。

## 3. 人手で追加した辞書外9件

作成者が指定した次の9件を、言い換えテストで使用することを確定した。これらはQwenが生成した全文指示でも、承認済み545件から選んだレコードでもない。人手で作成・選定した、辞書外の短い単純操作表現である。

| 操作ID | 終止形 | 接続形 | 役割 |
|---|---|---|---|
| `atomic-000001` | 2で割り切れる値を残す | 2で割り切れる値を残して | 偶数の間接表現 |
| `atomic-000001` | 奇数を除く | 奇数を除いて | 偶数の補集合表現 |
| `atomic-000002` | 2で割り切れない値を残す | 2で割り切れない値を残して | 奇数の間接表現 |
| `atomic-000002` | 偶数を除く | 偶数を除いて | 奇数の補集合表現 |

| `atomic-000014` | 各要素を二倍にする | 各要素を二倍にし | 漢数字表現 |
| `atomic-000015` | 全部を3倍する | 全部を3倍し | 算用数字表現 |

特に`atomic-000018`と`atomic-000021`を加えることで、23件側で不足する2操作を補う。

## 4. 言い換えテスト用32件

承認済み辞書の`test_only` 23件と、人手追加9件を合わせた32件を言い換えテスト用の単純操作表現とする。

```text
承認済み545件内のtest_only: 23件
人手作成の辞書外表現:        9件
合計:                       32件
```

32件により24操作すべてを覆う。操作ごとの表現数は均一ではない。

| 操作ID | 表現数 |
|---|---:|
| `atomic-000001` | 3 |
| `atomic-000002` | 3 |
| `atomic-000003` | 2 |
| `atomic-000013` | 2 |
| `atomic-000014` | 2 |
| `atomic-000015` | 2 |
| 上記以外の18操作 | 各1 |

32件の本文、接続形、表現IDは、訓練指示、validation、通常・組合せ・反復・境界値テスト、教師全文言い換えのfew-shot例へ一切渡さない。

## 5. 全文指示への組み合わせ方

言い換えテストは`normal`と同じ1,202意味AST、同じ正解コード、同じhidden test入力を使用する。変更するのは日本語表現だけとする。通常テストとの差を日本語表現の違いへ限定するため、新しい意味ASTや実行入力を加えない。

全文の接続規則と外側文テンプレートは、[`rule_generated_instruction_policy.md`](rule_generated_instruction_policy.md)と同じものを使う。最後以外の操作に接続形、最後の操作に終止形を使い、意味AST順を変えない。

### 主評価集合

主評価では1意味ASTにつき1件を決定的に選び、1,202件の全文指示を作る。操作別の使用回数を更新しながら、その操作で使用回数が最も少ない表現を優先する。同順位だけを固定seedと`spec_id`のSHA-256で決める。

これにより、表現数が3件ある偶数・奇数操作を含むASTだけが評価件数を多く持つ偏りを避け、通常テストの1,202意味ASTと1対1で比較できる。主評価レコードには対応する通常テストの`spec_id`を保存する。

### 全組合せ診断集合

診断用には、各意味ASTで利用できる32表現の直積をすべて組み合わせる。同じ全文は除外する。現在の1,202意味ASTでは、ASTごとの全文数は1〜12件、合計2,653件になる。

この2,653件は、特定表現ごとの失敗分析に使う。表現数の多い操作を含むASTほどレコード数が増えるため、全レコードを単純平均した値を主スコアにはしない。報告する場合は操作別・表現別、または意味ASTごとの平均を併記する。

## 6. 懸念点と対処

### 評価件数の偏り

操作ごとの表現数が1〜3件で異なる。全直積だけを評価すると、偶数・奇数などの操作が過大に重み付けされる。主評価を1意味AST1件、全直積を診断用に分ける。

### 辞書外9件の来歴

9件にはQwenの生成記録がない。Qwen生成と誤認しないよう、別JSONLへ保存し、`source=human_authored_out_of_dictionary`を必須とする。承認済み545件の`generation_record`を捏造しない。

### 短い表現の曖昧さ

`kを掛ける`は目的語を省略し、`その数と自らをかける`は前文脈へ依存する。単独の辞書項目としてではなく、意味AST順の全文へ組み込んだ状態で最終確認する。意味が変わる組合せは人手で`unused`にできるよう、表現IDと完成全文を確認用CSVへ出す。

### トークナイザによる評価の混同

32件を学生モデルの訓練データだけでなく、トークナイザ学習コーパスにも入れない。言い換えテスト実行時には、32件の文字・subwordが未知トークンになる割合を別に集計する。未知トークンが多い場合は、「意味の言い換えに失敗した」のか「トークン化できなかった」のかを分けて報告する。

### 表現単位の未学習性

32件の全文字や単語が訓練側へ一度も現れないことまでは要求しない。要求するのは、終止形・接続形の完全な表現組とその表現IDを訓練へ入れないことである。したがって、このテストは完全な未知語テストではなく、未学習の操作表現を理解できるかを測る。

## 7. 分割の再現方法

公開済みCSVと生成来歴JSONLから、次を実行する。

```bash
uv run --python 3.12.12 python \
  scripts/instruction_generation/build_approved_expression_dictionary.py \
  --config config/build_approved_expression_dictionary.json \
  --overwrite
```

出力は次の2ファイルである。

| ファイル | 内容 |
|---|---|
| `data/instruction_dictionaries/approved_expressions.jsonl` | 545件すべてに`train`または`test_only`を付け、元の生成レコードも保持した利用用辞書 |
| `data/instruction_dictionaries/approved_expression_stats.json` | 総数、区分別件数、操作別件数、選定ID、辞書バージョン |

この2ファイルは公開CSVと来歴JSONLから再生成できる派生物なのでGit管理しない。人手選定の再現に必要な23件のIDは設定JSONとしてGit管理する。

## 8. 検査条件

分割処理は次を満たさない場合に停止する。

1. 公開CSVと来歴JSONLが545件で、行単位のID、操作ID、終止形、接続形が一致する。
2. 人手選定IDが23件で、すべて公開CSVに存在する。
3. `train=522`、`test_only=23`になる。
4. 23件が22操作を覆い、`atomic-000003`だけ2件、`atomic-000018`と`atomic-000021`は0件になる。
5. 出力各行が生成時の`generation_record`を保持する。
6. 人手追加JSONLが9件で、すべて`dictionary=test_only`、`source=human_authored_out_of_dictionary`である。
7. 23件と9件の表現IDが重複せず、合計32件で24操作を覆う。
8. 32件の終止形・接続形がtrain 522件の完全な表現組と重複しない。
9. 主評価がnormalの1,202意味ASTと1対1対応し、全組合せ診断が2,653件になる。
