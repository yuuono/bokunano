# Boku Nano 1Mモデル・1エポック学習／評価結果

## 結論

同じ1,016,704パラメータの1Mモデルを、既存BPEと短いpiece用BPEの2種類でランダム初期値から1エポック学習し、固定済み5テスト84,550件で評価した。

| 項目 | 既存BPE | 短いpiece用BPE |
|---|---:|---:|
| 5テスト合格 | 1,467 / 84,550（1.7351%） | 4,572 / 84,550（5.4075%） |
| 日本語言い換え | 2 / 30（6.6667%） | 0 / 30（0.0000%） |
| 通常テスト | 446 / 24,040 | 1,636 / 24,040 |
| 組合せ汎化 | 103 / 13,400 | 260 / 13,400 |
| 同一操作の反復 | 508 / 23,040 | 1,073 / 23,040 |
| 境界値 | 408 / 24,040 | 1,603 / 24,040 |

短いpiece用BPEは5集合合計で既存BPEより3,105件、3.6724ポイント高かった。ただし、日本語言い換えは既存BPEの2件だけが合格し、短いpiece用BPEは0件だった。どちらも実用的なコード生成モデルとしては未学習に近く、1M・1エポックでは容量または学習量が不足している。

## モデルと学習結果

両モデルはトークナイザー以外を揃えたDecoder-only Transformerである。

| 項目 | 値 |
|---|---:|
| hidden size / 層数 | 128 / 3 |
| Attention head数 / 1 head次元 | 4 / 32 |
| FFN size / context length | 256 / 256 |
| 語彙数 / 総パラメータ数 | 2,048 / 1,016,704 |
| 位置表現 / 正規化 | RoPE / RMSNorm |
| dropout / 入出力embedding | 0.0 / 非共有 |

| 学習指標 | 既存BPE | 短いpiece用BPE |
|---|---:|---:|
| epoch / optimizer step | 1 / 377 | 1 / 377 |
| 学習時間 | 36.665秒 | 41.146秒 |
| 系列token | 6,939,466 | 17,281,995 |
| loss対象token | 3,746,067 | 10,233,836 |
| 訓練系列長 | 18〜94 | 35〜137 |
| unknown token | 0 | 0 |
| 最終Train loss | 1.386624 | 0.530280 |
| Validation loss | 1.378111 | 0.524322 |
| Validation perplexity | 3.967401 | 1.689313 |

短いpiece用BPEは同じ192,900レコードを2.490倍の系列token、2.732倍のloss対象tokenへ分割した。token単位が異なるため、lossとperplexityの絶対値をトークナイザー間で直接比較してはいけない。

## 評価条件

[評価器](../../scripts/model/evaluate_boku_nano.py)と固定評価ZIPを使い、参照コードとの文字列一致ではなく機能一致で判定した。greedy生成、最大160 token、bfloat16、1生成コードあたり5秒timeoutとし、構文・安全AST・signature・入力非変更・最大64件のhidden入力をすべて満たした場合だけ合格とした。詳細は[モデル評価方針](../policies/boku_nano_model_evaluation_policy.md)を参照。

短いpiece用モデルは無限反復する生成が多いため、この実行に限り固定入力検証を32並列化した。先頭1,024件を逐次版と再評価し、結果JSONLがバイト単位で一致することを確認した。判定条件は変更せず、一時変更は評価後に元へ戻した。

## 日本語言い換え30件の詳細

テストの作成方法と表現の由来は[言い換えテスト指示の生成・モデル評価結果](paraphrase_test_instruction_results.md)に記載している。今回も同じ30指示と同じhidden入力64件を使用した。

| 指標 | 既存BPE | 短いpiece用BPE |
|---|---:|---:|
| 合格 | 2 | 0 |
| 静的検査不合格 | 8 | 10 |
| 実行時例外 | 4 | 8 |
| 意味不一致 | 16 | 11 |
| timeout | 0 | 1 |
| 平均prompt token | 14.60 | 24.37 |
| 平均生成token | 14.17 | 38.27 |

「静的」は構文解析または未定義名検査、「実行」は生成関数内の例外、「意味」は実行できたが期待値と一致しなかったことを表す。

## 判断と成果物
